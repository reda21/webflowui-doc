Button

A flexible component that allows users to take actions, and make choices, with a single tap. Buttons can be customized with various styles, sizes, and icon positions.

Preview Stage v1 refresh Reset View

# Usage

App.tsx 
import { Button } from '@webmx/core';

function Example() {
  return (
    <Button variant="primary" size="lg">
      Click Me
    </Button>
  );
}

# Variants

Primary

The default state for primary actions.

Secondary

Used for alternative actions in a view.

Outline

Subtle border with no background until hover.

Ghost

Minimalist button for secondary controls.

# Props API

Property Type Default Description
variant 'primary' | 'secondary' | 'outline' | 'ghost' 'primary' The visual style variant of the button.
size 'sm' | 'md' | 'lg' 'md' Adjust the padding and font size.
isLoading boolean false Show a spinner and disable interactions.
isDisabled boolean false Disable all interactions and grey out.
