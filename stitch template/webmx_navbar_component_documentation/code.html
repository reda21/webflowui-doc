Positioning Guide

Fixed Positioning

The navbar stays fixed at the top of the viewport even while scrolling. Content slides underneath.

Sticky Positioning

The navbar scrolls with the page until it reaches the top, then sticks. Best for long landing pages.

Responsive by Default

WebMX Navbar automatically collapses into a hamburger menu on smaller screens. The mobile drawer is fully customizable and supports nested navigation items.

code Example Drawer Configuration
<Navbar.MobileMenu
  position="left"
  blur={true}
  showUser={true}
/>

Component Props

Prop Type Default Description
variant "glass" | "classic" | "minimal" "glass" The visual style of the navbar container.
isFixed boolean false Whether the navbar stays fixed at the top of the viewport.
maxWidth "sm" | "md" | "lg" | "xl" | "full" "xl" The maximum width of the inner content container.
shouldHideOnScroll boolean false Hides the navbar when the user scrolls down.
