Components / Modal

Modal

A dialog is a window overlaid on either the primary window or another dialog window. WebMX Modals are built with accessibility in mind, supporting keyboard navigation, focus trapping, and ARIA attributes out of the box.

Interactive Preview

Confirm Action

Are you sure you want to proceed with this deployment? This action will overwrite the current production build and cannot be undone.

Variants

Standard

Standard dialog anchored to the top of the viewport with a fixed offset.

Full Screen

A modal that covers the entire viewport. Best for complex mobile interactions.

Centered

Perfectly centered horizontally and vertically for critical focus tasks.

Props Reference

Prop Type Default Description
isOpen boolean false Controls the visibility of the modal.
onClose function - Callback fired when the modal requests to close.
size 'sm' | 'md' | 'lg' | 'xl' 'md' The horizontal width of the modal content container.
isCentered boolean false Whether the modal is vertically centered.

Basic Usage

App.tsx 
import { Modal, ModalHeader, ModalBody, useDisclosure } from '@webmx/ui';

function Example() {
  const { isOpen, onOpen, onClose } = useDisclosure();

  return (
    <>
      <Button onClick={onOpen}>Open Modal</Button>

      <Modal isOpen={isOpen} onClose={onClose} isCentered>
        <ModalOverlay blur={"12px"} />
        <ModalContent>
          <ModalHeader>Confirm Action</ModalHeader>
          <ModalBody>
            Are you sure you want to proceed?
          </ModalBody>
        </ModalContent>
      </Modal>
    </>
  );
}
