Introduction

WebMX provides a set of high-quality React and HTML components designed to build premium, modern user interfaces with minimal effort. Our library focuses on performance, accessibility, and visual excellence through our proprietary Glass-Engine™ rendering technology.

terminal Installation

bash
$ npm install @webmx/core @webmx/theme

Configuration

Initialize WebMX in your project by creating a configuration file. This allows you to define your brand colors and global glassmorphism intensity.

webmx.config.js
export default {
  theme: {
    primary: '#0db9f2',
    presets: ['glassmorphism'],
    blur: '12px'
  }
}

Quick Start Usage

Glassy Card Component
import { Button, Card } from '@webmx/core';

function App() {
  return (
    <Card variant="glass">
      <Button color="primary">Explore WebMX</Button>
    </Card>
  );
}
